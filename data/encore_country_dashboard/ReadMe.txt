## About ##

This zip folder contains data (version 1.0) from the ENCORE Insights: Country Dashboard which has been developed as part of the Horizon Europe Nature 3B Project by Global Canopy (https://globalcanopy.org).

This data download includes the following files:
1. country_headline_figures.csv: Country level headline figures of value highly exposed in GVA and IVA (million Euros)
2. sector_depenency_levels.csv: Monetary values of dependency (million Euros): high, medium and low dependency for GVA and IVA at country, sector level
3. subsector_all_data.csv: Country - Subsector level data: Economic size (GVA and IVA in million Euros), direct (consolidated ENCORE ratings) and upstream dependency ratings (weighted mean dependency of domestic and foreign suppliers).
4. country_codes.csv: A key of EU27 country code to country name.

The full methodology can be downloaded from https://countries.encorenature.org. Definitions can be found on the Dashboard.
